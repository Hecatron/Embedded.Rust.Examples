This board is a ESP32-C6 with an onboard LCD, RGB Backlight and micro sd card slot

  * 160MHz RISC-V
  * 2.4GHz Wi-Fi 6 (802.11 b/g/n) 
  * BLE5
  * 320KB ROM, 512KB of HP SRAM, 16KB LP SRAM
  * 4MB Flash memory
  * Onboard TF card slot
  * 1.47inch screen attached
    172x320 LCD Screen 262K Color with RGB
  * Built-in RGB LED with clear acrylic sandwich panel for cool lighting effect
