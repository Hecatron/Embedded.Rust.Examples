# Firmware Updates

## Latest STLink

The latest STLink firmware can be downloaded from

  * <https://www.st.com/en/development-tools/stsw-link007.html>

it's basically a Java app that can update the STLink portion of the dev board
which normally handles the USB interface and JTag
At the time of writing I've updated it to 3.16.7

## Jlink Firmware

The STLink can be converted to a segger via

  * <https://www.segger.com/products/debug-probes/j-link/models/other-j-links/st-link-on-board/>
